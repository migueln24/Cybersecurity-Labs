# Project: Linux Command Line Fundamentals

## Objective
The purpose of this project is to demonstrate foundational proficiency in navigating the Linux command line, managing files, processing text, and installing software packages.

## Skills Demonstrated
- **Package Management:** Installed software in a Linux distribution using `apt`.
- **Standard I/O:** Examined and redirected input/output streams in the Linux shell to efficiently manage command results.
- **File System Navigation & Search:** Utilized Linux commands to locate specific files and directories across the file system.
- **Text Processing:** Applied `grep` to filter text output and isolate critical information within files.

## Tools Used
- Linux Bash Shell
- Advanced text filters (`grep`)
- Standard I/O operators (`>`, `>>`, `<`)
- Advanced search utilities (`find`)

## Outcome
Successfully executed core administrative tasks via the command line environment, demonstrating the ability to efficiently search, filter, and manage system resources without a graphical user interface (GUI).
