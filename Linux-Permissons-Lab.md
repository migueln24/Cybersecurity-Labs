# Project: Managing Linux File Permissions

## Objective
The goal of this lab was to demonstrate proficiency in navigating the Linux file system, examining directory contents, and modifying file permissions to ensure the principle of least privilege. 

## Skills Learned
- Navigating the Linux terminal using `cd`, `pwd`, and `ls`.
- Reading and writing file outputs using `cat`, `head`, and standard I/O redirection.
- Modifying user access and group permissions.
- Troubleshooting syntax and path errors in a live Bash environment.

## Tools Used
- Linux Command Line / Bash Shell
- Package Managers (`apt`)

## Steps Taken
1. **System Reconnaissance:** Navigated through the directory structure to locate target security configuration files. 
2. **Access Control Verification:** Checked current file permissions using `ls -l` to identify unauthorized access risks.
3. **Permission Modification:** Reconfigured read, write, and execute permissions on sensitive files to restrict access only to authorized user groups.
4. **Validation:** Installed and verified necessary packages, and verified that the terminal output matched the expected security posture.

## Outcome
Successfully restricted file access according to best practices, demonstrating a core understanding of Identity and Access Management (IAM) at the operating system level.
